# v1.0.22

## Fixed

**Live Amazon Offers card now actually shows** — the regexes in the offer scrape were
built against an outdated Amazon markup and silently returned nothing. Now verified
against a real live Amazon.ca product page:

- **New / Buy Box price** — reads the `priceToPay` → `a-offscreen` span on the
  product detail page (the buy box price).
- **Lowest Used** — now pulled from the search scrape's "More buying choices"
  snippet (the detail page loads used offers via JavaScript, so they're not in the
  initial HTML).
- **Offer count** — extracted from the search result's "N used & new offers" text.
- **Sales rank** — reads "Best Sellers Rank: #N in Category" from the detail page
  (regex fixed: no "Amazon" prefix, no colon, trailing paren stripped).

## Added

- `offerCount` is now part of the search scrape result, feeding the offer card.
