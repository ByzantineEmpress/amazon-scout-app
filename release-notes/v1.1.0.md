**A rebuilt interface, starting with History and Settings.** This is the first step of a ground-up
redesign: one set of colours, spacing and type instead of nine separate ones, so the screens finally
belong to the same app.

### ✨ New

- **History rebuilt.** Prices, verdict badges and how long ago on every row, a proper search box,
  and an empty state that explains itself. It opens full screen rather than as a sheet.
- **Settings rebuilt.** Grouped by what they affect, and they save as you change them — there is no
  Save button to forget. The update check and install live in one place, with your version shown.

### 🐛 Fixed

- **Tapping the 🇨🇦 / 🇺🇸 marketplace pill on the scanner crashed.** It called a function that was
  never imported, so switching marketplace from the main screen threw instead of switching.
- **The "sound effects" switch did nothing.** The setting was stored and read back, but no part of
  the app has ever played a sound. Removed rather than left as a control that lies to you.

### 📝 Worth knowing

- History and Settings now open full screen instead of sliding up as sheets.
- Next in the rebuild: the tabbed shell (Scan · Comps · History · Settings) so every tool is one tap
  away, then a single result screen shared by barcodes, printed ISBNs and photos.
