**Sell-through now actually appears.** v1.0.26 shipped the feature, but it never reached the screen —
the two counts were fetched and the rate worked out, then dropped before the display, so nothing
showed anywhere. Fixed, with a test that fails if that wiring is ever broken again.

### 🐛 Fixed

- **Sell-through was invisible.** The scan card and Photo Comps now show the rate and the counts
  behind it. Before, both showed nothing at all.
- **When a rate cannot be worked out, the card says so** instead of leaving a gap — "Sell-through
  unavailable for this search" — so a missing rate is never mistaken for a broken feature.

### 📝 Worth knowing

- "Sell-through unavailable" means eBay did not return a readable count for that search. Your price
  is unaffected: the count request is allowed to fail on its own.
- The rate remains an estimate: eBay's sold count covers roughly the last 90 days while the listed
  count is right now, and both count listings rather than units.

### ✅ Unchanged

- Barcode scanning, Amazon prices, sold prices, the comps pane, and in-app updates.
