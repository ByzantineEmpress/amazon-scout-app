**Sell-through is read from the comps page itself, and the search can be narrowed to the right
category.** eBay refuses the app's own requests with a 403, which is why the sell-through figures
never appeared: the app was asking for data eBay will not serve to it. It now reads the numbers out
of the page the comps view actually loads.

### ✨ New

- **Sell-through in the comps view**, read from the sold and listed counts on the pages themselves
  and shown at the top with the two counts beside it — "Sell-through 64% · 128 sold / 72 listed" —
  with the same green/amber/red reading as before.
- **"Narrow to Books & Magazines"** — one tap scopes the search to the category eBay has put the
  search in, and tapping it again returns to all categories. The header shows what is applied.
- **The category comes from eBay**, not from a list baked into the app. A wrong category id returns
  *nothing at all*, so guessing one would be worse than not filtering.

### 📝 Worth knowing

- **The figure on the scan card comes from a background request eBay usually refuses** (HTTP 403),
  so it will often be missing — that has been true for a while and is why the sell-through never
  showed up there. The comps view is where eBay's data is really available, so that is where the
  real numbers now are.
- Sell-through is still an estimate: eBay's sold count covers roughly the last 90 days while the
  listed count is right now, and both count listings rather than units.
- If a rate cannot be worked out, the view says "Sell-through unavailable for this search" rather
  than leaving a blank, so a missing number is never mistaken for a broken feature.

### ✅ Unchanged

- Barcode scanning, Amazon prices, sold prices, and in-app updates.
