# v1.0.25

## Fixed

**"Used Pricing" section still showed the wrong price** — after v1.0.24 fixed the "Live Amazon
Offers" card to use the detail page, the separate "Used Pricing" section at the bottom of the
result was still showing the old search-snippet price ($4.99 instead of $21.56 for "Dark Room").

The app shows two price sections:
- **Live Amazon Offers** — buy box, lowest used, offer count, sales rank (detail page)
- **Used Pricing** — lowest used, buy box (was: search snippet, now: detail page)

Both sections now pull from the product detail page ("Other sellers on Amazon"), which is
authoritative for the specific ASIN. The search-snippet values remain as fallbacks for when the
detail page scrape fails.
