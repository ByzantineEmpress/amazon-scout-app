**Two fixes for the "Scan Printed ISBN" screen.** Its camera showed a black bar instead of a
preview, and reading a number clicked like a camera shutter every second. Both are fixed.

### 🐛 Fixed

- **The viewfinder works now.** The main scanner was still holding the camera while this screen
  was open, so the second camera just rendered black. The main preview now steps aside — only one
  camera can use the device at a time.
- **No more shutter sound.** Reading a number captured a frame roughly every 0.7 seconds and each
  one clicked, which is unbearable in a quiet shop. Captures are silent now, and the screen no
  longer flashes white on every frame.
- **"Starting camera..." instead of a blank box**, and a clear message if the camera cannot start
  at all, rather than an unexplained black area.

### 📝 Worth knowing

- The ISBN screen needs a moment to take the camera over from the main scanner. That is the
  "Starting camera..." pause, and it is deliberate.
- If you have not installed v1.0.14 yet, install **this** release by hand and skip that one — you
  do not need both.

### ✅ Unchanged

- Barcode scanning, prices, restriction warnings, and in-app updates all work as before.
