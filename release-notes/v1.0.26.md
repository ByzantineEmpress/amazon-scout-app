**Sell-through rates, and a fix to used pricing.** Comps now show what share of the listings for a
search have actually sold — the quickest read on whether something moves or sits. This release also
carries a fix for the Used Pricing section, which was quoting a price from a search snippet.

### ✨ New

- **Sell-through, with the numbers behind it.** A percentage alongside the two counts it came from —
  for example "Sell-through 64% · 128 sold / 72 listed" — coloured green, amber or red so it reads
  at a glance. It appears on the scan card and on Photo Comps.

### 🐛 Fixed

- **The Used Pricing section quoted the wrong price.** It was still reading a search snippet rather
  than the product detail page, so it could say $4.99 for something selling used at $21.56. Both
  price sections now use the detail page, with the snippet kept only as a fallback if that scrape
  fails. (This was cut as v1.0.25 but never reached anyone, so it is included here.)

### 📝 Worth knowing

- Sell-through is an estimate, and it is presented as one. eBay's sold count covers roughly the last
  90 days while the listed count is right now, and both count *listings* rather than units — a
  listing offering five copies counts once. It is only as meaningful as the search terms above it.
- **The rate only appears when both counts can be read.** A count that cannot be read is never
  treated as zero, so you will not see a false 0% on something that sells perfectly well.
- It costs one extra request per item, so the price can take a moment longer to appear. That request
  is allowed to fail on its own: if it does, you still get the price.

### ✅ Unchanged

- Barcode scanning, Amazon prices, sold prices, the comps pane, and in-app updates.
