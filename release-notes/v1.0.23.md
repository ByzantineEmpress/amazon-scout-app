# v1.0.23

## Fixed

**Wrong book shown when two titles share a name** — scanning "Dark Room" by Alex North
returned "Dark Room" by Elsevier Health Sciences. The Amazon search scrape grabbed the
first non-digital result with a used price, without checking whether it was actually the
book you scanned.

Now, for book searches, the app verifies that the result's ASIN matches the scanned ISBN
before accepting it. If a different book with the same title appears first in the search
results, it is skipped and the correct ISBN-matched result is used instead.

- ASIN matching handles both ISBN-10 and ISBN-13 queries (a book's ASIN equals its
  ISBN-10 digits; the check normalizes both forms).
- Non-book searches (DVDs, games, media) are unaffected — they still take the first
  physical result with a price.
- Falls back to the best physical result if no ISBN-matched result is found, so the
  fix never makes results worse.
