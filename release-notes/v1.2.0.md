**A tabbed shell you can switch on now.** Scan, Comps, History and Settings each get their own tab,
so nothing is hidden behind a button on the camera screen. It is opt-in while the redesign finishes:
Settings → Interface → "New interface".

### ✨ New

- **Four tabs, one tap apart:** Scan · Comps · History · Settings. Android's back button returns to
  Scan instead of leaving the app.
- **The scanner, redesigned** on the same system as the rest: marketplace chip, torch, zoom,
  tap-to-focus, and a reticle that tells you when a code is being confirmed. The validation gate
  underneath is untouched — two agreeing frames and a check digit, exactly as before.
- **Switch to it whenever you like:** Settings → Interface → "New interface", and back the same way.

### 📝 Worth knowing

- **The result screen and the photo-comps screen still look like the old app.** They work, they are
  reachable from the tabs, and rebuilding them is the next step. Everything else is new.
- **The classic interface is unchanged and still the default**, so trying the new one cannot break
  your day — one switch puts it back.
- One structural change worth knowing: only the active tab exists, which means the scanner's camera
  is released the moment you leave it. That used to have to be remembered in each screen.

### ✅ Unchanged

- Scanning, prices, restriction warnings, sold prices, sell-through, and in-app updates.
