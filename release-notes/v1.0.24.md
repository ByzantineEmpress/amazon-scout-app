# v1.0.24

## Fixed

**Wrong lowest-used price when a book shares its title with another edition** — scanning
"Dark Room" by Alex North showed $4.99 (a different "Dark Room" by Elsevier) instead of the
actual lowest used price of $21.56.

The app was pulling the "Lowest Used" price from the Amazon **search results** page, which can
be polluted by a different book with the same title. It now reads the price from the **product
detail page** ("Other sellers on Amazon" section), which shows the lowest price for *this
specific ASIN* only.

Also fixed:
- **Offer count** now comes from the detail page's "Compare all N options" link, not the search
  snippet.
- **New / Buy Box price** falls back to the search snippet's buy box price if the detail page
  scrape fails.

The detail-page values are authoritative for the specific book. The search-snippet values remain
as fallbacks for when the detail page is unreachable.
