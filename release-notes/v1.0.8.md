**⚠️ Reinstall required — one time only.** This version is signed with a new release key, so
Android cannot install it over an older copy. Uninstall Amazon Scout, then install this APK.
In-app updates work normally again from here on.

No functional changes in this version. It is a release-engineering update: every APK is now
signed with a private release key, and the build refuses to publish anything it cannot verify.

### 🛠 Under the hood

- Release APKs are signed with a private PKCS#12 release keystore. Earlier releases were signed
  with the public Android debug key that ships inside the React Native template — a key whose
  alias and password are public, which meant anyone could have signed an APK Android would
  accept as a genuine Amazon Scout update.
- The build now fails if the release tag and the app's version disagree, so the in-app updater
  can never be handed a version it will never see cleared.
- Build toolchain refreshed (Node 22) and every GitHub Action pinned to a commit SHA.

### 🗑 Removed

- The unused *"GitHub Token (for Private Repos)"* field in Settings. The repository is public,
  so the update checker never needed it — and it was storing a credential on the device.
