**Updates install from inside the app now.** Tap **⚙️ Settings → Check for Updates →
Install Update** and it downloads and goes straight to Android's installer — no more browser, and
no .apk left sitting in your Downloads folder to hunt down later.

### ✨ New

- **In-app updates.** The download happens inside Amazon Scout with real progress on the button,
  then Android asks you to confirm the install. Your scans, settings and history are all kept.
- **A way out if Android blocks it.** If the install is refused, the app offers a shortcut to the
  permission Android needs, plus a browser fallback, instead of just failing.

### 📝 Worth knowing

- Android always asks you to confirm an install for an app that did not come from the Play Store.
  That is the platform's rule, so there is one final tap — but the browser and the stray file are
  gone for good.
- **This particular release still needs installing by hand**, from the release page below. Every
  release *after* it updates in-app.

### ✅ Unchanged

- Scanning, prices, restriction warnings, and the release notes you are reading here all work
  exactly as before.
