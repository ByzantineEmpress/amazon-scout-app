**The app has been rebuilt — this is the new interface.** Four tabs, one design system, and one
result screen shared by barcodes, printed ISBNs and photos. Everything you could do before, you can
still do, in a layout that tells you where you are.

### ✨ New

- **Four tabs: Scan · Comps · History · Settings.** Nothing is buried behind a button on the camera
  any more, and Android's back button returns you to Scan instead of leaving the app.
- **One item screen for every way of finding something** — scan it, type it, read a printed ISBN, or
  tap a row in History — with the verdict, Amazon's prices, the comps search and the actions in the
  same order every time.
- **One comps view**, where sell-through, the category and eBay's listings live, read from the page
  itself because eBay refuses the app's own requests.
- **One design language:** a single set of colours, spacing and type, replacing nine separate style
  sheets and 38 ad-hoc colours. Every screen is built from the same components.
- **The photo screen rebuilt** too, so all three ways in look and behave alike.

### 📝 Worth knowing

- **The old interface is still there for one release**, in case anything gets in your way:
  Settings → Interface → "Classic interface (temporary)". It will be removed in the next version.
- **Nothing about the data changed.** Scanning, the validation gate, Amazon prices, restriction
  warnings, sell-through, comps and updates work exactly as before — this release is the interface.
- The verdict is still a local guess from the publisher and ISBN, and the item screen now says so
  plainly rather than implying an answer from Amazon.
