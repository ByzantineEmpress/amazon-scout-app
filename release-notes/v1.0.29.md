**The category is applied to the comps search on its own now, and nothing covers the page while it
loads.** Offering a "narrow to…" chip was too easy to miss, so the category eBay puts the search in
is applied automatically — one tap clears it. The full-screen loading cover is gone.

### 🐛 Fixed

- **The category is actually applied.** It was only ever offered, so the search stayed unscoped and
  full of unrelated items. The category eBay puts the search in is now applied as soon as the page
  reports it, named in the header, and one tap on the chip goes back to searching all categories.
  That choice is remembered for the rest of the visit.
- **Nothing sits over the page while it loads.** A full-screen overlay used to dim the results and
  could stay up when a load was interrupted — eBay redirecting, for instance — leaving the page
  looking cut off. It is removed, and the strip at the top says "reading eBay…" instead.
- **The loading state is cleared by the page itself**, not only by the load-finished callback, which
  is the same problem from the other side: a page that answered is a page that loaded.

### 📝 Worth knowing

- Applying a category means searching within that department. If the comps look thin, tap the
  category chip in the header to search everything again.

### ✅ Unchanged

- Barcode scanning, Amazon prices, sold prices, and in-app updates.
