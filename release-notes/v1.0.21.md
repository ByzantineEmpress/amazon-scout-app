**Scanner is now far more reliable, and the result card shows real Amazon offer prices.**

The biggest change: the app now scrapes Amazon's *product detail page* (not just the search
results) after a scan, so the result card shows the live **New / Buy Box** price, the **lowest
Used** offer, the **offer count**, and the **sales rank** — the same "exact Amazon pricing" the
paid scouting apps show. It's shown alongside the existing search-snippet prices, never instead
of them, and only when the detail scrape returns something.

The second change is scanner accuracy. The frame-agreement gate is now **time-windowed** (a code
must agree three times within 2.5 s, not just two consecutive reports), **spatially stable** (the
code must appear in roughly the same place across frames), and a **rejected read is now visible**
(a brief toast instead of silent). Case/carton barcodes (ITF-14) are no longer scanned by default
— they were a major source of "scanned a case, got the wrong item" false reads — but you can turn
them back on in Settings if you scan multi-packs.

### ✨ New
- **Live Amazon Offers** card on the result screen: New / Buy Box, Lowest Used, offer count, and
  sales rank, pulled from the product detail page (keyless, no API).
- **Spatial stability gate**: a code must be read in the same place across frames to confirm, so a
  steady second barcode in the frame (a case code, a shelf tag) no longer triggers a lookup.
- **Time-windowed confirmation**: a code must agree three times within 2.5 s. A code you've moved
  away from is no longer silently carried over.
- **Rejection toast**: when a read is dropped (bad check digit, not a product barcode, etc.), you
  see a brief toast instead of nothing.
- **"Scan case/carton codes" toggle** in Settings: enables ITF-14 for multi-packs and retail boxes.

### 🐛 Fixed
- Case/carton (ITF-14) codes are no longer scanned by default, eliminating the "scanned a case,
  got the wrong item" class of false read.
- A steady misread that repeats for two consecutive frames no longer passes the gate (now needs
  three agreeing frames within the window).
- A 13-digit EAN-13 with a 1-digit tail is no longer misread as a UPC-A plus a 1-digit add-on.
