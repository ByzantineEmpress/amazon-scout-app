**Items with no name to read — a bare controller, a camera body, a drill — now work.** They have
no product name printed on them, but they almost always have a model number, and that is exactly
how used gear is titled on eBay. Point the camera at the label on the underside.

### ✨ New

- **Model numbers are read out of the small print.** A loose controller usually offers nothing but
  a sticker, and searching that number finds the item precisely instead of approximately.
- **"Model read: …" appears as a tap**, so you can search just the model number in one go.
- **When nothing is readable, the app says where to point instead** — the label on the back or
  underside, which is where the model number lives.
- **The search field puts the cursor in it** when nothing could be read, so typing a couple of
  words takes seconds.

### 📝 Worth knowing

- Compliance marks such as EN71, ASTM and RoHS are deliberately *not* treated as model numbers —
  they look identical and would send you to the wrong comps.
- A model number is only folded into a descriptive name when that name is a single word. eBay
  requires every word you search to appear in a listing, so a stray extra term would return
  nothing at all rather than slightly worse results.
- For an object with no text anywhere — no sticker, no marking — there is genuinely nothing to
  read, and the app asks you to type a couple of words rather than guess. A guess from shape alone
  would return the price of every vaguely similar object, which is worse than no answer when you
  are deciding what to pay.

### ✅ Unchanged

- Barcode scanning, Amazon prices, book comps, and in-app updates.
